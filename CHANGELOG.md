# Changelog

## 0.2.0 (2026-11-10)

- Require Statamic 6 and PHP 8.3 or newer. Statamic 5 sites should stay on 0.1.x.
- Migrate the Bard extension, toolbar, popover, and event listeners to Statamic 6 and Vue 3.
- Use Statamic's current input and button components to restore control panel styling.
- Preserve input focus and the existing Apply, Enter, Cancel, and Remove actions.
- Update the standalone build tooling and include rebuilt control panel assets.
- Add rendering tests for existing annotations, formatting, nested content, and escaped pronunciation text.

Existing stored content and frontend HTML are unchanged; no content migration is required.
